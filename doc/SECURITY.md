# 安全说明

## 数据分类

采集包和报告属于机密运维数据，可能包含主机名、IP、账号、进程、端口、数据库
对象、告警日志和 SQL 指标。不要通过公共聊天、公共网盘或未加密邮件传输。

建议使用受控文件传输通道，并配置访问审计、最小权限和自动保留期。完成报告后，
应按组织策略清除中间采集包及不再需要的报告。

## 凭据

- 不要在 `check.conf`、Shell 参数或环境日志中保存数据库密码。
- 优先使用 Oracle OS 认证；也可使用运行时隐藏输入，跨服务认证建议使用 Oracle Wallet。
- Linux 与 Windows 的交互认证密码只保存在 Collector 当前进程内存中，通过 SQL*Plus 标准输入建立连接，不进入进程参数、配置和采集文件。
- 调试模式只应用于受控环境；v4.3 隐藏认证信息，但日志仍可能包含敏感路径和 SQL。

## 可选数据

`COLLECT_SQL_TEXT` 和 `CHECK_AWR` 默认关闭。启用前需同时确认数据分类要求和
Oracle 授权范围。

## 传输

采集端打包时只生成 tar.gz 数据包。请使用具备访问控制和传输保护的受控通道
转移采集包，并按组织策略限制访问范围和保留时间。
