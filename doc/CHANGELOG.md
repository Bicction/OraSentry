# 变更记录

## 未发布

### 采集与认证

- Windows Collector 新增 `开始巡检.cmd` 双击入口，自动申请管理员权限、读取统一配置并在结束时显示采集包路径；命令行入口保持兼容。
- Windows 配置项同步为 Linux 命名规则，`DB_INTERACTIVE_LOGIN=on` 使用运行时交互认证，关闭时自动选择 Wallet 或 OS 认证。
- Windows 主机新增10秒CPU/内存/换页/磁盘持续采样、Oracle端口防火墙规则、关键事件分类、补丁与待重启状态，以及 Oracle 服务恢复动作和进程资源采集。
- Windows 数据库采集新增 Data File、Redo、控制文件、FRA、归档和诊断路径与盘符容量关联。
- 修复 Windows 独立主机/数据库入口的命名参数转发，`-NoPack` 与 `-InteractiveLogin` 可正常传递。

### 评分与报告

- Windows CPU、内存和磁盘优先按持续采样的P95判定，旧版采集包继续回退单点指标。
- 防火墙关闭、默认允许入站、Oracle端口对任意远程地址开放、关键事件、Oracle服务/进程不一致、补丁过旧和待重启均形成独立风险项。
- 网络监听端口改为信息清单，不再把“存在监听”无条件判定为健康。

## 4.3.0 - 2026-08-30

### 采集与认证

- 新增 `collector-windows` 原生 PowerShell 5.1 采集端，支持 Windows 主机、Oracle 数据库、安全配置、Alert Log、Trace、Listener 和 NTFS ACL 巡检。
- 原 Linux `collector` 更名为 `collector-linux`，统一入口更名为 `OraSentry.sh`，并增加 `platform=linux` 协议字段。
- Linux 与 Windows 主机采集包统一为 `host_check_<hostname>_<timestamp>.tar.gz`；数据库包继续使用 `db_check_<SID>_<timestamp>.tar.gz`。
- 数据协议升级为 4.3，同一报告器根据 `platform` 分流主机与操作系统安全解析，同时继续接受历史 4.x 包。
- Windows Collector 内置 ustar+gzip 打包实现，不依赖 Windows Server 是否预装 `tar.exe`。
- 采集打包不再生成同名 `.sha256` 校验文件，打包阶段只输出 tar.gz 数据压缩包。
- `check.conf` 新增默认关闭的 `DB_INTERACTIVE_LOGIN`；开启后运行时依次提示 IP、端口、连接类型、服务名/SID、账号、隐藏密码和角色，同时避免密码进入配置、进程参数、调试日志及采集包。连接类型默认使用与 Easy Connect `主机:端口/服务名` 一致的 `SERVICE_NAME`，并保留显式 SID 连接。
- 数据库 SQL*Plus 调用统一经过安全连接入口，保留既有 OS 认证和 Oracle Wallet 模式，并支持 11g 的 `SYSDBA`、`SYSOPER` 与普通角色登录。
- 交互认证改为先以 `/nolog` 启动 SQL*Plus，再通过标准输入执行包含安全引用密码的 `CONNECT`，修复 19c 将无密码角色登录误判为 `SP2-0306` 或不触发密码提示的问题；密码仍不进入进程参数、配置与日志。
- 数据库版本/能力探测失败时直接显示安全筛选后的 ORA/TNS/SP2/LRM 错误，不再要求先开启调试模式才能判断连接失败原因。

### 评分与报告

- 新增 Windows 固定卷、CPU、内存、页面文件、磁盘延迟、登录事件、防火墙、时间同步、监听端口、事件日志和 Oracle 服务报告项。
- Linux inode、sysctl、HugePages/THP 等项目在 Windows 报告中明确标记为不适用，不参与健康评分。
- Windows Oracle Home、二进制、网络配置与密码文件改按 NTFS ACL 检查宽泛写权限。
- 健康评分改为按适用检查项业务权重归一化，取消固定扣分和 59/79 分硬封顶。
- 新增 `INFO` 与 `UNKNOWN` 状态；AWR按配置关闭、架构不适用和采集完整性不再冒充正常项或重复扣减健康分。
- 风险状态、健康评分和数据可信度独立展示，采集失败时评分明确标记为仅供参考。
- 单份报告、GUI和多系统汇总统一使用同一评分模型；风险排名优先考虑数据异常和核心严重风险。
- 主机内存检查优先使用 `MemAvailable`，旧内核按 `MemFree`、缓冲区和可回收缓存兼容估算，修复 CentOS 6 的 `cached` 列被误当成 `available`；报告统一展示实际占用、可用内存、缓冲/缓存和计算口径。

## 4.2.0 - 2026-08-24

### 正确性与性能

- 主机报告与 Oracle 数据库报告彻底分离，避免巡检项混用。
- Alert Log 固定通过 `Diag Trace` 和当前 `ORACLE_SID` 定位实例物理日志。
- Alert Log 只截取文件尾部10万行分析最近30天内容，并记录截断状态。
- 报告展示 Alert Log 物理大小，超过2GB提示及时归档清理。
- Word 报告保留打开即显示、可点击跳转的静态目录，移除单独的“章节索引”，并取消自动更新域以避免安全提示。
- Word 报告的“总结”改用标题段前分页，避免上一章节刚好写满时产生额外空白页。
- Word 静态目录增加与书签实际分页一致的页码；页码由 Word 分页引擎在生成时缓存并锁定，不启用全局更新域，也不创建外部文件关系。
- FORCE LOGGING 未启用改为提示项，并修复 SQL*Plus 截断表头造成的误判；自动扩展表空间统一按最大使用率进行状态判定和图表着色。
- 表空间概览按最大使用率降序；数据文件未自动扩展与 ASM 高使用率指标增加醒目高亮。
- Alert Log 报告改为展示标准化的实际分析时间范围，不再向用户展示内部的尾部行数上限。
- 缓冲区物理读与逻辑读计数改用普通十进制格式，避免科学计数法。
- HTML 与 Word 共用巡检项用途说明，补充各项检查目的和关注重点。
- HTML 巡检说明改为普通文字并折叠在“展开详情”末尾，避免抢占检查结果的视觉层级。
- 实例状态采集改查 `GV$INSTANCE` 并展示全部实例，支持 RAC 多实例状态核查。
- 兼容旧版 Linux `procps` 的 CPU、内存进程采集字段。
- 防火墙关闭或 INPUT 默认 ACCEPT 按 Oracle 主机合理配置处理。
- 主机磁盘容量检查结合 `mounts.txt` 识别只读光盘和不可变镜像，避免 `iso9660` 等文件系统正常的 100% 使用率被误报为磁盘空间严重告警；普通 `/mnt` 可写磁盘仍正常参与阈值判断。
- Swap 检查改为占用率与实时换页组合判断：容量阈值调整为 50%/80%，忽略 `vmstat` 开机累计行，仅在持续 `si/so` 活动时提前告警，避免历史换出页导致的低占用误报。

### 工程化

- 采集器、报告生成器、数据协议与 Windows EXE 版本统一升级为4.2。
- OracleReport“项目与输出”新增默认关闭的“生成总结”选项；启用后自动填写每份 HTML 与 Word 详细报告末尾的总体结论、重点问题和处置建议，关闭时总结章节保持空白。
- OracleReport 生成状态改用圆形旋转图标并保持普通鼠标指针；新增“停止生成”按钮，可在安全检查点终止批次并保留此前完整生成的报告。
- OracleReport 图形界面按“数据源—项目与输出—生成—结果”的操作顺序重新布局，统一现代化配色与状态反馈；报告生成、解析和阈值判定逻辑保持不变。
- 图形界面新增“项目名称”，默认值为 `ORACLE INSPECTION REPORT`，可自定义 Word/HTML 报告封面标识；Word 封面项目名称固定使用宋体且不使用斜体。
- 图形界面简介精简为“导入采集数据，生成HTML和Word报告”；Word 详细报告与汇总报告的页脚统一显示界面填写的项目名称。
- OracleReport 数据选择区支持从资源管理器直接拖入 `.tar.gz`、`.tgz` 采集包或包含采集包的文件夹，并沿用目录展开和路径去重规则。
- Word 详细报告和汇总报告移除开头空白页，正式封面调整为第 1 页，目录页码随分页结果重新计算。

## 4.1.0 - 2026-08-24

### 安全

- 移除配置文件明文数据库密码认证，避免密码进入进程参数和调试日志。
- 增加 Oracle Wallet 无密码连接入口。
- SQL 文本和 AWR 采集改为默认关闭。
- 采集包增加机密数据标识、权限收紧和 SHA-256 校验文件。
- 报告端保留用户已有旁路文件。
- 解压失败、生成成功及生成失败后均回收程序创建的临时目录。

### 正确性

- 主机包与数据库包改为始终分别生成报告，Oracle 报告全面移除主机巡检章节。
- Alert Log 只使用 `v$diag_info` 的 `Diag Trace` 拼接当前实例 `alert_${ORACLE_SID}.log`；先高效截取文件尾部10万行，再分析其中最近30天内容，超出范围时明确标记截断。报告同步展示物理日志大小，超过2GB提示及时归档清理。
- 新增 4.x 数据协议校验。
- 健康评分区分警告和严重，并与总体状态区间一致。

### 工程化

- 版本统一为 4.1.0。
- 固定运行与构建依赖版本。
- Windows EXE 增加文件版本资源、SHA-256 文件和 Authenticode 签名说明。
- 增加根级文档、升级说明、安全说明和 CI 配置。
