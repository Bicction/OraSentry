# 从 v4.1 升级到 v4.2

v4.2 将采集器、报告生成器和 Windows EXE 统一升级为 4.2，采集包写入
`schema_version=4.2`。报告端继续接受同一主版本的 4.x 采集包。

## Alert Log

- 只通过 `v$diag_info` 的 `Diag Trace` 拼接 `alert_${ORACLE_SID}.log`。
- 只读取物理日志最后 100,000 行，并在其中分析最近 30 天内容。
- 报告展示分析行数、截断状态和物理日志大小。
- 物理 Alert Log 超过 2GB 时提示归档和清理。

升级后请使用 v4.2 采集器重新采集，旧包因缺少新增字段只能按兼容模式生成报告。
