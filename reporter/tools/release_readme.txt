OraSentry Oracle 自动化巡检 v4.4 — 快速启动版

1. 将整个 OracleReport-FastStart 文件夹解压到有写权限的本地目录。
2. 双击文件夹内的 OracleReport.exe。可以为此文件创建桌面快捷方式。
3. 必须保留同目录的 _internal 文件夹；不能单独复制 EXE。
4. 首次解压后，日常启动无需重复释放临时运行环境。
5. 无需安装 Python。可离线生成 HTML 和 Word 报告。
6. 默认报告输出在程序旁 output/report 中；也可在界面选择其他输出目录。

单文件便携版 OracleReport.exe 可单独复制，启动时会显示品牌页和旋转指示。
两个版本功能相同，推荐日常使用本目录版。
